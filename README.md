CIT Bus Tracker (Full Stack)
Backend: Node.js + Express (server.js) — login, bus data, driver GPS updates
Frontend: public/index.html, public/style.css, public/app.js — Leaflet map
Run locally
npm install
npm start

Open http://localhost:3000

Demo logins: student1 / student123, driver1 / driver123

Deploy

GitHub Pages cannot run a backend. Deploy this repo on Render (free): New → Web Service → connect repo → Build: npm install → Start: npm start. Your Render URL will serve both the backend and the frontend.
